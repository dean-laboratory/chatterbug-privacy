# Chatterbug 개인정보처리방침

Chatterbug 앱의 개인정보처리방침을 GitHub Pages로 공개하는 저장소입니다. Google Play 등록정보와 OAuth 동의 화면에 이 페이지 주소를 넣습니다.

| 언어 | 파일 | 공개 주소 |
| --- | --- | --- |
| 한국어 | `index.md` | `https://dean-laboratory.github.io/chatterbug-privacy/` |
| 영어 | `en/index.md` | `https://dean-laboratory.github.io/chatterbug-privacy/en/` |
| 일본어 | `ja/index.md` | `https://dean-laboratory.github.io/chatterbug-privacy/ja/` |

공개 주소는 GitHub Pages를 켠 뒤에 열린다. 내용이 서로 다르면 한국어 방침을 따른다고 본문에 적어 두었다.

## 고칠 때

1. 앱에 새 기능이 들어가 다루는 정보가 바뀌면 한국어 `index.md`를 먼저 고치고, 영어와 일본어를 같은 뜻으로 맞춘다. 예: 구독 결제, 기기 안 AI 모델 내려받기.
2. 시행일을 바꾸고, 시행일 7일 전에 공개한다.
3. 이전 방침은 커밋 기록으로 남는다.
