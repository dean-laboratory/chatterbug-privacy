# Chatterbug 개인정보처리방침

Chatterbug 앱의 개인정보처리방침을 GitHub Pages로 공개하는 저장소입니다. Google Play 등록정보와 OAuth 동의 화면에 이 페이지 주소를 넣습니다.

- 본문: `index.md`
- 공개 주소: GitHub Pages를 켜면 `https://dean-laboratory.github.io/chatterbug-privacy/`

## 고칠 때

1. 앱에 새 기능이 들어가 다루는 정보가 바뀌면 `index.md`를 고친다. 예: 구독 결제, 기기 안 AI 모델 내려받기.
2. 시행일을 바꾸고, 시행일 7일 전에 공개한다.
3. 이전 방침은 커밋 기록으로 남는다.
